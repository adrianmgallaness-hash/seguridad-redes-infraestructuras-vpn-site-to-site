# Evidencias gráficas

Guardar aquí las capturas y diagramas utilizados para documentar las tres infraestructuras.

## Organización

```text
images/
├── infraestructura-1/
├── infraestructura-2/
└── infraestructura-3/
```

Usar nombres descriptivos, por ejemplo:

```text
infraestructura-1/01-topologia.png
infraestructura-1/02-vpn-up.png
infraestructura-1/03-https-200-ok.png
```

Las capturas deben mostrar solo la información necesaria para comprobar los objetivos del laboratorio.
