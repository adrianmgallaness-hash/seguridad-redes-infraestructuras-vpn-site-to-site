# Scripts

Scripts utilizados durante las pruebas del laboratorio.

## HTTPS

`https_server.py` inicia un servidor HTTPS simple para validar la comunicación con el servidor Ubuntu.

Los archivos `cert.pem` y `key.pem` no deben publicarse si contienen material privado real.

## StrongSwan

La configuración de ejemplo para la Infraestructura 3 se encuentra en:

`configs/infraestructura-3/strongswan-ipsec.conf.example`

Las credenciales reales no están incluidas.
